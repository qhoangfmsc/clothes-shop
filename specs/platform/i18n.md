# i18n (đa ngôn ngữ) — Tech spec

> **Nhóm:** Platform · **Cập nhật:** 2026-10-22 · **Trạng thái:** Implemented
> **Doc:** [platform/i18n](../../docs/platform/i18n.md) · **Test:** `tests/platform/i18n/`

## 1. Bối cảnh & mục tiêu

Mọi chữ hiển thị đi qua `next-intl`. Sai ở đây làm lộ khóa dịch, lệch bản `vi`/`en`, redirect sai hoặc metadata SEO sai ngôn ngữ. Module có phần thuần (metadata, đọc lỗi, định dạng), phần hook (nhãn, lỗi), middleware và công cụ `scripts/i18n.mjs` (sinh registry, kiểm đủ khóa). Chưa có test nào.

**Mục tiêu.** Phủ toàn module theo ma trận, khóa hành vi hiện tại, tách phần thuần của `scripts/i18n.mjs` thành `scripts/i18n-lib.mjs` để test được, và gom định dạng ngày/số vào `src/i18n/formats.ts` (hiện bị chép ở harness test).

## 3. Hợp đồng

- `routing`: `locales ["vi","en"]`, `defaultLocale "vi"`, `localePrefix "always"`, `localeDetection false`. `LOCALE_LABELS` có mục cho mọi locale (`name`, `short`, `ogLocale`).
- **Middleware.** Đường dẫn không bắt đầu bằng `/<locale>` (đúng bằng `/vi`, `/en` hoặc bắt đầu `/vi/`, `/en/`; phân biệt hoa thường) → chuyển hướng vĩnh viễn 308 tới `/vi` + đường dẫn + query (`/` thành `/vi`). Đường dẫn có tiền tố → chạy middleware của `next-intl` (không chuyển hướng). `matcher` bỏ qua `api`, `media`, `_next`, `_vercel` và mọi đường dẫn có dấu chấm (file).
- **`request.ts`.** Locale hợp lệ được giữ; không hợp lệ hoặc thiếu → `vi`. Trả `messages` của locale, múi giờ `Asia/Ho_Chi_Minh` và `formats` (số: `decimal1`; ngày: `short`, `long`, `dateTime`, `monthYear`).
- **`pickMessages(messages, scopes)`** giữ đúng các nhóm gốc được nêu. **`ScopedMessages`** gửi `common`, `shared`, `auth` cộng đúng một nhóm (`public`, `private` hoặc `admin`).
- **Metadata.** `buildAlternates(locale, path)`: `canonical = /<locale><path>`, `languages` có mọi locale và `x-default` trỏ locale mặc định. `withBrand(t)` = `t — DOOVAN`. `buildSocialMetadata`: Open Graph `website` với `locale`, `alternateLocale` (các locale còn lại), `url`, ảnh (ảnh trang hoặc ảnh thương hiệu 1200×630, `alt` mặc định là tiêu đề) và Twitter `summary_large_image`.
- **Lỗi.** `errorCodeOf(err)`: `errorCode` là số, hoặc `code` là chuỗi số nguyên; còn lại `undefined`. `errorText(err)`: `message` là chuỗi, còn lại rỗng. `useErrorMessage()(err, fallback)`: bản dịch `shared.errors.byCode.<code>` nếu có, rồi `message` của lỗi, rồi `fallback`; hàm trả về ổn định giữa các lần render cùng locale.
- **Nhãn.** `useOrderStatusLabel`, `useOrderPaymentStatusLabel`, `useAddressFieldLabel`, `useRoleLabel`: bản dịch `common.<nhóm>.<giá trị>` hoặc chính giá trị nếu chưa có.
- **Công cụ.** `placeholders(text)` trả tên đối số ICU cấp ngoài cùng (đã sắp xếp, nhánh lồng nhau bị bỏ qua). `compareLocale` báo: thiếu khóa, giá trị không phải chuỗi hoặc rỗng, khác `{placeholder}`, khóa lạ.

## 4. Thiết kế

```
URL ─► middleware (308 /vi/...) ─► next-intl middleware ─► request.ts (locale, messages, formats) ─► layout
layout ─► NextIntlClientProvider (common, shared, auth) ─► ScopedMessages (public | private | admin)
Component ─► useTranslations ─► useErrorMessage / use-labels
scripts/i18n.mjs ─► i18n-lib.mjs (flatten, placeholders, compareLocale) ─► sync registry.ts | check
```

## 5. Quyết định thiết kế

### Design pattern

| Quyết định | Lý do | Phương án đã bỏ |
|---|---|---|
| **Một nguồn sự thật cho ngôn ngữ**: `routing.locales` đọc bởi middleware, metadata, công cụ | Thêm ngôn ngữ chỉ sửa một chỗ | Danh sách locale ở nhiều nơi |
| **Fallback hiển thị giá trị gốc** (`use-labels`) | Trạng thái mới từ BE vẫn hiện được | Ném lỗi khi thiếu bản dịch |
| **Chuỗi ưu tiên cho lỗi** (mã → text server → fallback đã dịch) | Người dùng luôn thấy chữ đúng ngôn ngữ nếu có thể | Luôn hiện text server (tiếng Anh) |
| **Functional core** `i18n-lib.mjs` | Luật kiểm bản dịch test được không cần dựng cây thư mục | Giữ trong script chạy ngay khi import |
| **Dữ liệu cấu hình dùng chung** `formats.ts` | Server (`request.ts`) và harness test dùng cùng định dạng | Chép định dạng vào harness |

### Kiến trúc

`src/i18n/` là lớp nền: lib thuần (`metadata`, `error-message`, `formats`, `routing`), hook (`use-labels`, `use-error-message`), cấu hình server (`request`, `ScopedMessages`) và middleware ở `src/`. Không phụ thuộc module nghiệp vụ. Message theo role (`public/private/admin`) tách để storefront không tải bản dịch admin.

### SOLID

| Nguyên tắc | Áp dụng thế nào ở module này |
|---|---|
| S | `metadata.ts` chỉ dựng metadata; `error-message.ts` chỉ đọc lỗi; `use-labels.ts` chỉ tra nhãn |
| O | Thêm locale = thêm vào `routing` và thư mục message; mọi nơi khác tự nhận |
| L | Mọi hook nhãn có cùng chữ ký `(value) => string` |
| I | Hook trả hàm nhỏ, không trả cả `t` |
| D | Component gọi hook, không gọi `Intl` hay đọc file message |

**Nợ đã biết:** `errorMessage` (cũ) vẫn export và còn 2 nơi dùng trong `src/app`; rule `error-message` của `check-conventions` cấm dùng nó ở `src/app` nên các nơi đó cần chuyển sang `useErrorMessage` (làm ở module của chúng).

### Conventions

Tiếng Anh cho code. Chữ hiển thị chỉ nằm ở `src/messages/**`. Test lấy chữ qua `msg("khóa")`, kiểm cả `vi` và `en`.
